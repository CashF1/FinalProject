GOLF CLUB MANAGEMENT SYSTEM

DESC
The Golf Club Management System is a Django web application designed to help namage golf club players, tournaments, and scores. Users can add, view, edit, and delete player adn tournament records, enter golf scores, and view a leaderboard

FEATURES

Player management
Tournament management
Register players for tournaments
Enter golf scores
View a golf leaderboard
Django admin interface
Golf themed styling

TECHNOLOGIES USED

Python
Django 6.1.1
SQLite
HTML
CSS

SETUP INSTRUCTIONS
1. Install Python
2. Download or clone the repository
3. Open a terminal in the project folder
4. Install the required package:
    python -m pip install -r requirements.txt
5. Apply database migrations:
    python manage.py migrate
6. Start the development server::
    python manage.py runserver
7. Open http://127.0.0.1:8000/ in a browser
